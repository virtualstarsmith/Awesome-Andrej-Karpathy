# Contributing to Awesome Andrej Karpathy

Thanks for your interest in contributing!

## Inclusion Criteria

A project must satisfy **one** of the following:

- **A — Official**: Maintained or published by Karpathy himself. No bar.
- **B — Direct derivative**: The project's own README/About explicitly says *inspired by / port of / based on* a Karpathy repo, video, or essay.
- **C — Concept derivative**: The project explicitly cites one of Karpathy's named concepts (Software 2.0/3.0, LLM OS, Vibe Coding, LLM Wiki, `CLAUDE.md`, AutoResearch, Recipe for Training NN, Pong from Pixels) with a link to the original source.

## Out of Scope

- Projects only mentioned in third-party blog posts or comment threads, with no provenance in their own README.
- Archived repos with <50 stars and no activity for 12+ months (multi-language ports excepted).
- Closed-source commercial products, unless they are an unavoidable node in the idea timeline.

## Entry Format

```
- [author/repo](https://github.com/author/repo) - One-line description ending with a period.
```

Use the appropriate prefix emoji from the Legend in the README. Add 🇨🇳 for Chinese-language projects. Multi-language ports go under their dedicated section. New sub-categories require a matching idea seed in Concepts & Manifestos.

## PR Process

- **Title format**: `Add: author/repo` or `Update: author/repo`
- One entry per PR (preferred)
- Include a link to where the project cites Karpathy (README, About page, etc.)
- New sub-categories need a matching idea seed in [Concepts & Manifestos](./README.md#concepts--manifestos)

## Updating Entries

Star counts, links, and descriptions drift. If you spot an outdated entry, open a PR with the corrected line.

## Removing Entries

If a repo is archived, the link is dead, or it no longer meets inclusion criteria, open an issue with the `remove` label.
