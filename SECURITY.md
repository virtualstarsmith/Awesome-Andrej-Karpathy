# Security Policy

## Listing Does Not Equal Endorsement

This is a **curated list, not an audit**. Listed projects are created and maintained by their respective authors. We do not audit, endorse, or guarantee the security, correctness, or licensing of any listed project.

## Risks of Listed Projects

Community skills, agents, and `CLAUDE.md` files can contain:
- Prompt injections
- Tool poisoning
- Hidden payloads
- Unsafe data-handling

**Review every project (including its dependencies) yourself before installing or running it in a privileged environment.**

## Reporting a Malicious Listed Project

If you find a listed project that is actively malicious:
1. Open a [GitHub issue](https://github.com/virtualstarsmith/Awesome-Andrej-Karpathy/issues) with the `security` label
2. Include the project URL and a description of the security concern
3. We will review and remove the entry if warranted

## What We Review

We verify that links are live and that entries meet our inclusion criteria. We do **not** audit the code, dependencies, or security posture of any listed project.
